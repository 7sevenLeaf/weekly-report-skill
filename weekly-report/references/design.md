# 主题怎么做

## 主题是一个比喻

不是换个配色。先找这一周最像什么东西，再让整页都变成它：

| 这一周 | 比喻 | 各模块变成 |
|---|---|---|
| 考试周 | 考卷 | 填空题（数据）、解答题（成就）、判断题（目标）、阅读理解（情绪）、错题本（复盘）、阅卷人的话 |
| 演出、创作 | 唱片 | 封套 + 唱片（封面）、主打歌（成就）、曲目（时间线）、旋律（情绪）、歌词本（话）、A/B 面（复盘） |
| 写代码、做项目 | 终端 | 敲命令出数据（封面）、提交记录（成就）、专注热力（像代码贡献图）、目标检查、注释（话）、diff（复盘） |
| 任何一周（首选） | 云白沉浸版 | 遮罩露出的周数 → 七张日卡展开 → 每天一个固定场景（时钟走、天色变、事一件件浮出）→ 成就卡 → 七天收拢 |
| 任何一周 | 编辑部（瑞士风格） | 占满版面的周数（封面）、编号小标题、大数字、发丝线、一个橙色 |

其他可以试的：登山路线（一周爬了多高）、天气预报、地铁线路图、菜谱、展览、球赛战报、植物生长记录。

## 一个主题文件夹

```
themes/<名字>/
  theme.json   名字、适合什么样的一周、Google Fonts 链接
  theme.css    改变量 + 改模块样式
  theme.js     改标题（labels）、印章文字（status）、复盘三栏名字（review）、封面（cover）、画完后加装饰（after）
```

`theme.js` 里写 `window.WR_THEME = {...}`。`story(c)` 在封面后面插一段主题自己的叙事，`modules` 选后面接哪些套件模块；`theme.json` 里写 `"scripts": ["gsap.min.js", "ScrollTrigger.min.js"]` 会带上 GSAP（许可见 `scripts/build.py` 开头）。`extras: ["heat"]` 打开 7×24 专注热力；`replay(c)` 是封面开场动画（录视频时会重播）。`cover(c)` 返回封面的 HTML；`c` 里有 `data`、`esc`、`fmt`、`icon`、`DAYS`、`$`、`$$`、`clamp`、`reduce`（用户要求减少动效时为 true）。

CSS 至少定这些变量：`--bg --bg2 --ink --ink2 --mute --rule --accent --accent2 --c-study --c-sport --c-sleep --c-life --c-star --font --font-num --font-say`。

## 质感

这些是从真实使用里攒下的教训：

1. **比喻要贯穿全页**，不能只有封面。封面之后每个模块的标题、印章、配色都在比喻里。
2. **封面第一屏**就要有三个核心数字。
3. **小画直接摆出来**，不要藏在「点开看」后面：截图和分享时，藏起来的等于没有。
4. **页面别太长**：手机上 8 屏左右。内容多就删，不要堆。
5. **字要读得清**：正文不小于 15px，说明文字不小于 13px。手写字体只用在短句上（答案、批注、落款），长段落用正常字体。
6. **少用小卡片拼格子**：同类内容收进一块，用细线分行。
7. **标题文字用纯色**，不做多色渐变字；颜色点在数字和图上。
8. **只有一套配色**，浅色深色选一个，不跟随系统切换。

## 颜色和数据图（第一轮打分后补，2026-11-18）

样张第一轮打分：考卷 6、唱片 8、电路板 4。扣分原因记在这里，以后的主题都要避开：

- **考卷 6：杂乱，数据和文字不清楚。** 装饰（密封线字、网格纸、注意事项框、手写长句）抢了数据的位置。
- **唱片 8：动效少。** 数据只是静态柱子，可以用更有创意的形式展示。
- **电路板 4：深绿配黄难看，不像代码，没有高级感。** 两个饱和色互相打架，发光效果显得廉价。

所以：

1. **一个强调色。** 纸、墨、五到七级灰，加一个强调色，就这些。强调色只标「这一页的主角」：最大的数、正在看的那条线。多个系列用强调色的深浅区分，不再加新颜色。（参考 [Hallmark](https://github.com/Nutlope/hallmark) 的配色纪律和 AI_Animation 的瑞士风格）
2. **不发光**：深色主题也不用 glow、霓虹、径向光斑、渐变字。
3. **先选图再画**：

   | 数据是 | 用 |
   |---|---|
   | 一个数 | 大数字 + 一句说明，不画单根柱子 |
   | 一周七天 | 柱子或点阵 |
   | 几项占整体多少 | 横向堆叠条，不用饼图、环图 |
   | 一天里哪几个小时 | 7×24 热力格 |
   | 走势 | 一条线，只在要说的点上加标记 |

4. **字和数分开**：数字用等宽数字（tabular-nums），标签用灰色正文字，不给文字染数据色。
5. **动效要讲数据**：数字从 0 滚到终值、柱子长出来、线条一笔画出来、点阵一格格亮起。每个动效都在说明这个数是怎么来的，不做纯装饰的循环动画。
6. **交互要多**：能切换的数据都给切换；时间线可以拖着看「这一刻在做什么」；小画点一下重播；热力格点一下看那一小时。

## 代入感、转场、清新色调（第二轮反馈后补，2026-11-18）

试用者的意见：现在是站在外面看总结，缺代入感；模块之间要有高级感的衔接；参考 Apple；**不要石墨、酒红、深灰这类沉色，要清新或有创意**。
她给的参考：Spotify Wrapped 的遮罩、Apple Vision Pro 的固定场景展开、scrollytelling、GSAP 首页、clip-path 帘子揭开。

1. **滑动就是时间在走**：页面主线按周一到周日走，屏幕上始终有「现在是这一周的哪一刻」（时钟）。按时间走的部分占页面 60% 以上。
2. **固定场景**：一个场景固定住，滑动推进里面的变化（GSAP ScrollTrigger 的 pin + scrub）。每个场景约滑 0.9 到 1.4 屏，太快显得急，太慢显得拖。
3. **至少五种转场**：遮罩露字、卡片展开、斜切换场、帘子揭开、底色随当前项变化、逐字出现、数字跟着滑动滚出。
4. **清新的三层配色**（从她给的四张参考图量出来）：
   - 底：中性浅灰或白，亮度 88–99、彩度 ≤0.025，占画面 60% 以上；
   - 粉彩：类别色，亮度 78–98、彩度 0.04–0.10，可以多个色相；
   - 主角：一个鲜亮的冷色（钴蓝、紫）或明黄，彩度 0.15–0.20，只占画面约 1–3%。
   - 不要：深色背景、石墨、酒红、深灰、米黄旧纸色当大面积底色。

## 意象、炫技、数据交互（第三版打 6 分后补，2026-11-18）

试用者：「简洁高级感还可以，但有点普通，没有眼前一亮；可以加炫技动画、数据交互、元素意象的可视化。」
实测第三版：叙事部分图形只占画面 1.8%，41 屏里 39 屏没有能点的东西，全屏的炫技时刻 0 个。所以：

1. **每类数据找一个意象，画出来，而且由真实的数决定它的样子**：
   - 一周 168 小时 → 168 个方块（颜色 = 那一小时在做什么），拼成周数，再排成 7×24；
   - 一天 → 一片天空：太阳按时钟走；月亮圆缺 = 今晚睡够没有，星星数 = 睡了几小时；云和雨 = 当天的情绪；
   - 学习 → 一小时一本书，越摞越高；运动 → 心跳线跳起来；
   - 成就 → 3D 卡片翻上来、数字滚轮转到结果、彩纸。
2. **叙事里也要能玩**：拖太阳调时间、点书看是哪一段、点云看心情、拖卡片倾斜、按住数字和上周比。
3. **粉彩意象要有对比**：粉彩画在粉彩天空上会「隐身」。意象要大（太阳半径约画面宽度的 8%），带光晕，山坡用比天空深一级的颜色。
4. 用同一把尺子量：录屏逐帧算「不是底色的像素占比」和「彩色图形占比」，和参考视频比。

## 每天一个主角（第四版打 7 分后补，2026-11-18）

试用者的例子：化学可以摇试管、跑步可以跑起来、失落时小雨不够鲜明、每天的色调可以换、用当天的主题元素做大块转场、毛玻璃面板、每天的数据换一种展示方式。
她特别说明：**这些是启发，要演绎成通用的做法**，不是只做这几个例子。所以云白用 `themes/cloud/lead.js` 做了一套「主角」规则：

1. **每件事归一个意象类型**：实验、考试、读书、代码、跑步、游泳、力量、球、音乐、见面、放松、休息。新的事按关键词和图标归到最接近的一类。
2. **心情看分数也看原话**：慌 → 焦虑（闪电、字发抖）；累/阈值 → 疲惫（天色变暗）；难受 → 低落（大雨、水花、字往下掉）；！！ → 兴奋（彩虹、星光、字跳起来）。
3. **选主角**：强烈的情绪 > 当天的成就 > 高光事件 > 花时间最多的事；一周里重复的主角降权，七天尽量不一样。
4. **主角决定这一天**：色调（主色 + 浅色）、天空里的主题小场景、进场的大块转场（液面上涨、雨滴、跑道、声波、铅笔、翻页、圆形扩散）和跟着边缘走的大元素、心情特效、数据面板的形式。
5. **正在做的事有自己的小动画**：时钟走到哪件事，天空里就换成那件事的场景。
6. **数据面板七种，一周不重复**：一天 24 小时圆环、科目条、24 小时色带、仪表盘、半小时点阵、24 小时表盘、今天对比这周平均。考试日用仪表盘，情绪低的日子用点阵，运动日对比平均，学了两门以上用科目条；色带、点阵、表盘跟着时钟实时走。
7. **面板用毛玻璃**（半透明白、背景模糊、增饱和、内高光），背后放当天颜色的柔和色块，玻璃才看得出来。

## 更大胆、更通透、处处能玩（第五版打 8 分后补，2026-11-18）

试用者：转场可以再大胆；总结区单调；毛玻璃不够透明高级；每天的面板除了事件表没有别的交互。

1. **转场分两层**：主角颜色的色带领先铺过去，新的一天在后面跟着露出来；主角的大元素占屏幕宽度约 70%，沿边缘走、旋转、放大缩小，周围带一圈粒子。
2. **毛玻璃**：白只用 12–34% 的渐变，模糊 30px、饱和 210%，渐变描边、左上角高光、四边内光；背后必须有颜色（当天的色块、总结区的极光），否则玻璃看不出来。
3. **每块数据面板都能直接操作**，而且操作会带动画面：
   - 圆环、图例 → 点一类，中间换成那一类的时长和占比；
   - 科目条 → 点一门，列出具体是哪几段，并跳到那一刻；
   - 色带、表盘 → 按住拖时间，天空、太阳、活动场景跟着走；
   - 点阵 → 点一格，跳到那半小时；
   - 仪表盘 → 点一下在学习和睡眠之间切换，指针弹过去；
   - 对比 → 点一行，画出这一项七天的走势，今天标出来。
4. **总结区每块换一种形态**：168 小时用大环图（点一段）、目标用进度环卡片、原话用左右滑的彩色卡、复盘用一叠能翻的卡、信随着下滑一句句亮起来并画一笔签名。
5. 用 `tools/interact.mjs` 把所有交互点一遍、拖一遍，确认没有报错、每一步读数都对。

## 细节（第六版打 8.5 分后补，2026-11-19）

1. **转场边缘一律用平滑曲线**：阶梯、方块边缘在两层（色带 + 新的一天）错开时会叠成格子，看起来像坏了。液面、雨帘、声波、跑道都用曲线。
2. **人物动作要按关节做**：大腿、小腿、上臂、小臂分段，对侧手脚同相摆动，腿往后摆时膝盖弯得最多，身体前倾、轻微上下起伏。
3. **标签不压标题**：主角标签排在日期下面，不用绝对定位叠在标题上。
4. **翻卡片用 3D 角度动画**，进场只轻轻浮上来；不要把飞入、旋转、翻面混在一次动画里。

## 温度（第七版打 9.5 分后补，2026-11-19）

这几条做进了套件（`assets/kit.js`、`kit.css`），所有主题自动有，主题只换配色和字：

1. **数据都要「长出来」**：横条、圆环、百分比进场时从 0 长到实际值，数字跟着一起数。环用一个普通补间同时写 CSS 变量和数字，不要直接补间 CSS 变量（GSAP 读不到终点，环会一直停在 0）。
2. **原话用暖色纸卡和楷体**（霞鹜文楷），卡片下面一句助手的走心评价（`quotes[].note`）；左右滑。每个主题按自己的气质给卡片配色：考卷是便签、编辑部是暖白加红引号、唱片是黄色歌词卡、终端是带注释的代码块。
3. **信按方面写**：学习、身体、睡眠、心情、高光、下周，每段带标签，用这周真实的数字。
4. **翻面、背面也用当天的浅色**，不要用深灰、黑底：压抑。整套主题都不用石墨深底（终端也改成了浅色编辑器）。
5. **小人动作先看真实动作再画**：自由泳是身体平躺在水线、两臂差半圈轮流划、移臂时肘弯着出水、腿小幅快打；水分身前身后两层，水下的部分才看得出在水里。用 `tools/vignette.mjs <类型>` 逐帧检查。

## 交付前检查

分三档，参考了 [Hallmark](https://github.com/Nutlope/hallmark) 的分档办法。

**底线（不过不交）**

- [ ] `build.py` 检查通过
- [ ] 400px 宽没有横向滚动，控制台没有报错
- [ ] 没有编造的数据；解读标明了是谁的读法
- [ ] 系统开了「减少动效」时，页面照样完整可读
- [ ] 文字和背景对比清楚

**常犯（要有理由才能留）**

- [ ] 用了两个以上的强调色，或者用了发光
- [ ] 装饰比数据显眼

- [ ] 开头放了一句总结全周的金句
- [ ] 同一个数字出现了三次以上
- [ ] 比喻只在封面，后面变成普通列表
- [ ] 成就写成了流水账

**打磨（不挡交付）**

- [ ] 每件成就都有自己的小画
- [ ] 下滑时有进场动效
- [ ] 至少三处能点
