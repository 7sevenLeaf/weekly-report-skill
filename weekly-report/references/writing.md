# 内容怎么写

## 语气

像一个一起过了这周的伙伴：具体、克制、有判断。不打鸡血，不说空话。

- ✅「那道大题，正是你周二晚上专门重画过的那一类。」
- ❌「你真的太棒了！继续加油！」

## 成就

- 只写**做成了什么**：结果、突破、超额、第一次。不写流水账。
- `big` 用最能代表这件事的一个数或一个词：`92`、`全对`、`24:58`、`首演`。
- `detail` 用真实数据；`say` 是评价，点出这件事背后的原因或意义，一两句。
- 低谷周也找得到成就：扛过来的部分照实写。

## 小画（figure）

每件事画它自己的东西，一眼看得出在做什么：

| 事 | 可以画 |
|---|---|
| 考试、分数 | 分数轴上你和平均分的位置 |
| 跑步、配速 | 几次成绩连成的线和目标线 |
| 练琴、节拍 | 节拍器速度的台阶、五线谱 |
| 刷题、测试 | 一排打勾的格子 |
| 复习进度 | 章节格子，完成的涂满 |
| 写代码 | 测试点、耗时对比条 |

规矩：`viewBox` 宽 300；颜色只用主题变量（`var(--accent)`、`var(--ink)`、`var(--c-sport)` 等）；字用 `<text>`，11–15px；不放脚本。

## 目标对账

先写 `good`（做成的），再写 `gap`（差在哪）。主动调整的写 `moved`，不算失败。

## 起伏

- `level` 1–5。读不出来写 `null`，页面会留一个问号。
- `quote` 只放原话。没有原话就不写，页面会说「这天没有留下话」。
- `reading` 写你从这天的话和做的事里读到的，一两句。最低点那天写得最用心。

## 值得记住的话

只选深刻的感悟、建设性的想法、立下的规矩。进度汇报、训练数据不选。`after` 写后来怎么样了；没有真实的后续就不写。

## 复盘

- `good`：方法上做对了什么（可以复用的），不是重复成就。
- `improve`：具体到哪天、什么事，带一个能做的改法。
- `next`：正好三件，每件能在下周检查。

## 值得记住的话的评价（note）

一两句，像朋友回你这句话：点出它为什么重要、它后来带来了什么。不夸张，不说教，不重复原话。

## 信

按方面分段，每段带一个标签：学习、身体、睡眠、心情、高光、下周（没有数据的方面就不写）。
每段一两句，用这周的真实数字和具体的一刻；最后一段「下周」给三件能检查的事。

## 一件事只说一次

写完通读一遍：同一个数字或事实出现了三次以上，就删到只剩最该出现的那一处。
